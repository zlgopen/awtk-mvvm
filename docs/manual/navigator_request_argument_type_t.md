## navigator\_request\_argument\_type\_t
### 概述
导航请求的可选参数。
### 常量
<p id="navigator_request_argument_type_t_consts">

| 名称 | 说明 | 
| -------- | ------- | 
| NAVIGATOR\_ARG\_REQ | 导航请求的类型。 |
| NAVIGATOR\_ARG\_TARGET | 目标对象（比如窗口或ViewModel）的名称或路径。 |
| NAVIGATOR\_ARG\_OPEN\_NEW | 存在同名窗口时，是否打开新的窗口，当为true时则打开一个新的窗口，否则切换到已存在的窗口。 |
| NAVIGATOR\_ARG\_CLOSE\_CURRENT | 是否关闭当前窗口。 |
| NAVIGATOR\_ARG\_FORCE | 是否强制执行。 |
| NAVIGATOR\_ARG\_MIN | 最小值。 |
| NAVIGATOR\_ARG\_MAX | 最大值。 |
| NAVIGATOR\_ARG\_TITLE | 标题。 |
| NAVIGATOR\_ARG\_TIPS | 提示信息。 |
| NAVIGATOR\_ARG\_DEFAULT | 默认值。 |
| NAVIGATOR\_ARG\_DURATION | 超时时间。 |
| NAVIGATOR\_ARG\_CONTENT | 内容。 |
| NAVIGATOR\_ARG\_FOR\_SAVE | 用于保存。 |
| NAVIGATOR\_ARG\_FILTER | 过滤的内容。 |
| NAVIGATOR\_ARG\_PROPS\_CHANGED | 是否为属性改变的事件。 |
| NAVIGATOR\_ARG\_ITEMS\_CHANGED | 是否为集合中的项目增加或者删除的事件。 |
| NAVIGATOR\_ARG\_EVENT\_SOURCE | 事件源。 |
| NAVIGATOR\_ARG\_LANGUAGE | 语言。 |
| NAVIGATOR\_ARG\_COUNTRY | 国家或地区。 |
| NAVIGATOR\_ARG\_THEME | 主题。 |
| NAVIGATOR\_ARG\_TIME | 时间。 |
| NAVIGATOR\_ARG\_MODEL | 模型(用于创建子model)。 |
| NAVIGATOR\_ARG\_PREFIX | object wrapper的前缀。 |
| NAVIGATOR\_ARG\_VIEW\_MODEL\_TYPE | ViewModel的类型(让view model的创建函数有机会知道自己的类型)。 |
