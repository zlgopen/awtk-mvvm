## navigator\_request\_type\_t
### 概述
导航请求的类型，导航请求中不指定请求的类型时默认为打开一个新的窗口。
### 常量
<p id="navigator_request_type_t_consts">

| 名称 | 说明 | 
| -------- | ------- | 
| NAVIGATOR\_REQ\_CLOSE | 请求关闭指定窗口。 |
| NAVIGATOR\_REQ\_HOME | 请求回到主窗口。 |
| NAVIGATOR\_REQ\_BACK | 请求关闭顶层（最上面的）窗口。 |
| NAVIGATOR\_REQ\_TOAST | 请求打开内置的toast窗口。 |
| NAVIGATOR\_REQ\_INFO | 请求打开内置的提示窗口。 |
| NAVIGATOR\_REQ\_WARN | 请求打开内置的告警窗口。 |
| NAVIGATOR\_REQ\_CONFIRM | 请求打开内置的确认窗口。 |
| NAVIGATOR\_REQ\_PICK\_COLOR | 请求打开内置的颜色选择窗口。 |
| NAVIGATOR\_REQ\_PICK\_FILE | 请求打开内置的文件选择窗口。 |
| NAVIGATOR\_REQ\_PICK\_DIR | 请求打开内置的文件夹选择窗口。 |
| NAVIGATOR\_REQ\_COUNT\_VIEW\_MODEL | 请求获取指定的 View Model 的数量。 |
| NAVIGATOR\_REQ\_GET\_VIEW\_MODEL | 请求获取指定的 View Model。 |
| NAVIGATOR\_REQ\_NOTIFY\_VIEW\_MODEL | 请求触发指定 View Model 的变化事件。 |
| NAVIGATOR\_REQ\_GET\_LOCALE | 请求获取指定的本地化信息。 |
| NAVIGATOR\_REQ\_SET\_LOCALE | 请求设置指定的本地化信息。 |
| NAVIGATOR\_REQ\_GET\_THEME | 请求获取指定的主题。 |
| NAVIGATOR\_REQ\_SET\_THEME | 请求设置指定的主题。 |
| NAVIGATOR\_REQ\_SET\_SCREEN\_SAVER\_TIME | 请求设置屏保时间。 |
