## binding\_mode\_t
### 概述
绑定模式。
### 常量
<p id="binding_mode_t_consts">

| 名称 | 说明 | 
| -------- | ------- | 
| BINDING\_TWO\_WAY | 双向绑定，模型变化时自动更新视图，视图上数据变化时自动更新模型。 |
| BINDING\_ONE\_WAY | 单向绑定，模型变化时自动更新视图。 |
| BINDING\_ONE\_WAY\_TO\_VIEW\_MODEL | 单向绑定，视图上数据变化时自动更新模型。 |
| BINDING\_ONCE | 单向绑定，仅仅绑定一次。 |
