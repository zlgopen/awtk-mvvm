## view\_model\_event\_type\_t
### 概述
模型相关的事件。
### 常量
<p id="view_model_event_type_t_consts">

| 名称 | 说明 | 
| -------- | ------- | 
| EVT\_VIEW\_MODEL\_WILL\_MOUNT | 打开视图即将加载模型时通知view\_model。 |
| EVT\_VIEW\_MODEL\_MOUNT | 视图与模型绑定完成后通知模型。 |
| EVT\_VIEW\_MODEL\_WILL\_UNMOUNT | 视图即将关闭时通知模型。 |
| EVT\_VIEW\_MODEL\_UNMOUNT | 视图销毁时通知模型。 |
